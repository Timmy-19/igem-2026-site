# Plant Stress Bacterial Response System — iGEM 2026 Website

## Quick Start

```bash
cd igem-site
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build for Production

```bash
npm run build
```

## Pages

1. Home (/) — Landing page
2. Project Overview (/overview) — Scientific concept
3. Roadmap (/roadmap) — March–August timeline
4. Workstreams (/workstreams) — Execution logic
5. Ownership Dashboard (/ownership) — Operations hub
6. Weekly Updates (/updates) — Progress archive
7. Team Structure (/team) — Major/minor teams
8. Resources (/resources) — Centralized materials
9. Quick View (/quick-view) — Parent/instructor summary

## Tech Stack

React 19 + TypeScript, Vite, Tailwind CSS v4, React Router v7
